# Honor coordination and checkpoint authority
Coordination is local. No project board, forge automation or mandatory design-governance process is enabled. Follow human-directed scope and the selected contribution procedure for agent-owned spikes and reviewable contributions; a branch may carry multiple spikes and atomic commits. Installed service tools do not authorize messages, assignments or publication.

Make scoped local commits only when authorized under this project's checkpoint policy and honor review holds. Require explicit authorization for publication, remote changes, tooling installation, contacting teammates or altering a consuming project's governance. Never push. Never add a `Co-Authored-By:` trailer.

Use the actual [Commit Work](../../project-workflows/commit-work/SKILL.md) and [Coordinate Project Contribution](../../project-workflows/coordinate-project-contribution/SKILL.md) procedures; policy text does not grant tool access, change service permissions or establish another project's acceptance.
