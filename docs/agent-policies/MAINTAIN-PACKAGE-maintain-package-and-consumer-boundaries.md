# Maintain package and consumer boundaries
This repository owns the reusable DesignOps HackPack and its development documentation. Its direction is an agent-aware skills-and-tools package; the available reusable material consists of example specifications, assets and reference guidance. Do not claim that the planned skill/tool catalog already exists.

Read the [README](../../README.md) and material relevant to the requested operation. Templates, specifications and governance examples are resources to select and adapt; downloading the package does not adopt them as project authority. The consuming project's people, instructions, agreements and permissions remain authoritative. Keep its actual work, decisions and private data in its own workspace.

Maintainer records under `docs/` describe development of this package. Do not treat their open questions, proposals or task lists as consumer instructions, and do not create consumer projects or adopt governance merely because the package was opened. Broader governance implementation remains deferred in the [direction spike](../active-spikes/agent-aware-designops.md).
